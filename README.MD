# AbyssWalker

**A sci-fi puzzle adventure built with Python and Pygame.**

Welcome to **AbyssWalker**, a 2D desktop puzzle game inspired by classic Sokoban gameplay. Explore mysterious environments, restore unstable dimensional devices, and find your way through **40 solvable levels**.

Available in **English and Chinese**.

## About the Game

On a distant world undergoing a mysterious dimensional transformation, ancient devices have begun to fail. As an envoy sent to investigate, your mission is to restore these devices by pushing energy crates into their designated positions.

Every move matters. Navigate intricate layouts, avoid dangerous energy arrows, and activate the passage to the next challenge. Can you complete the journey?

## Features

- **40 solvable levels** featuring increasingly challenging puzzles.
- **Sokoban-inspired gameplay** that rewards planning and logical thinking.
- **English and Chinese** language options.
- **Distinct themed environments** with their own visual atmosphere.
- **Energy-arrow hazards** that add an extra layer of challenge.
- **Animated effects and sound** that bring the adventure to life.


## Download and Installation

AbyssWalker is packaged as a Windows desktop executable.

1. Visit this repository's **Releases** page when a downloadable release is available.
2. Download the Windows game package.
3. If the download is a ZIP archive, extract it first.
4. Launch **AbyssWalker.exe**.

**Note:** The packaged Windows version does not require you to install Python or Pygame separately. Only download executables from a source you trust.

## How to Play

Your objective is to push all energy crates onto their target positions. Once the puzzle is completed, a passage opens to the next level.

- Move through the level and push crates into place.
- Plan carefully: crates can be pushed, but not pulled.
- Avoid incoming energy arrows.
- Complete each level to advance through the adventure.
- Create a customer level after the last level.  

### Keyboard Controls

| Key | Action |
| --- | --- |
| Arrow keys | Move the player |
| `R` | Restart the current level |
| `U` | Recover the prvious crate position |
